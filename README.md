# Group_Lab_1_Group_06

Objectives:

Learn how to collaborate using GitHub
Practice working with branches and pull requests
Understand version control and code integration
Gain hands-on experience in collaborative coding
Project Description: Students will develop a basic Java program called TeamGreeting that prints a greeting message for each group member.

Each student in the group will work on a separate Java class:

Student 1: Member1.java - Prints a greeting from Member 1.
Student 2: Member2.java - Prints a greeting from Member 2.
Student 3: Member3.java - Prints a greeting from Member 3.
Student 4: Member4.java - Prints a greeting from Member 4.
Key Tasks
In this assignment you will follow the steps of the GitHub Collaboration Workflow:

1. Create a GitHub Repository:

One student creates a GitHub repository and adds group members as collaborators.
For this lab repository, please make it PUBLIC.
Name the repository: Group_Lab_1_Group_XX
Replace XX with your assigned group number.
Clone the repository locally.
2. Branching and Task Assignment:

Each student creates a new branch (feature-member1, feature-member2, feature-member3, feature-member4).
3. Implement Features:

Write code for the assigned task and commit changes to their respective branches.
4. Create and Merge Pull Requests:

Push the changes to GitHub.
Open a pull request (PR) to merge changes into the main branch.
Group members review the PR before merging.
5. Test and Finalize:

Ensure the program works as expected.
Merge all branches into main.
Submit the GitHub repository link.
